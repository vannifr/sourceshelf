# Reference

## Library layout

```
<root>/
  fiches/<id>.md        one metadata card per source (Markdown + YAML frontmatter)
  data/                 texts and files; keep out of git (a sibling of fiches/)
    text/<id>.txt       text written by `sourceshelf add` (`text:` may point to any path under data/)
    papers/, source-material/kb-add/   downloaded files and local imports
    logs/, run.lock     caches, run log, writer lock
  index/index.json      generated by `sourceshelf index`; commit it together with the fiches
  sources.yaml          optional, sources that `sourceshelf run` fetches
```

## Fiche format

Frontmatter keys: `id` (lowercase, `[a-z0-9._-]`), `title`, `status` (`new|seen|ignored|used|removed`), `origin` are required. Optional: `kind` (`peer-reviewed|preprint|report|news|blog|standard|other`), `url`, `doi`, `authors`, `year`, `date`, `fetched`, `file`, `text` (path under `data/`), `sha256` (of `file`), `text-layer` (`yes|no`), `open-access`, `confidential` (`yes|no`), `no-text` (reason; no text exists), `error` (last failure), `e-ids`, `source-file`, `machine-summary` (`text`, `model`, `prompt`, `date`, `truncated`, `verified`), `verification`.

Rules: machine output is marked (`machine:` block, `machine-summary`); a failed fetch has `status: new` and an `error:` line; `text:` and `file:` must stay inside `data/` (other paths are ignored). The Dutch key and value names of older libraries are still read.

`confidential: yes`: the title comes from the file name; search shows no snippet, page or line; `sourceshelf search --exact` skips the fiche and its text; the text is never sent to a model.

## sources.yaml

```yaml
sources:
  - id: arxiv-example        # unique, required
    kind: arxiv-query        # arxiv-query | url-list | feed
    query: 'all:"software testing"'   # arxiv-query only
    max: 10                  # items per run (default 10)
    cadence_days: 14         # required: minimum days between successful runs
  - id: pages
    kind: url-list           # urls: required for url-list and feed
    urls: [https://example.org/]
    cadence_days: 30
```

## Commands and exit codes

`0` success; `1` failure or nothing found (an empty search prints `no results` on stderr); `2` library folder not found. `sourceshelf check` exits 1 on any error; warnings do not fail it. A second writer (`add`, `describe`, `index`, `run`) exits 1 with "busy".

`sourceshelf search <query> [--limit N] [--fields] [--kind own|external] [--json]`, `sourceshelf search --exact <text>` (literal, needs `rg`), `sourceshelf get <id>`, `sourceshelf resolve <key>`, `sourceshelf due`, `sourceshelf run [source]`, `sourceshelf add <url|path> | --from <manifest>`, `sourceshelf inventory <dir>`, `sourceshelf describe <id>|--all`, `sourceshelf serve [--port]`. `sourceshelf <command> --help` lists the options.

`sourceshelf search --json` prints a list of `{id, title, score, path, page, line, snippet}`; no hit prints `[]` with exit 1.

## Web API (`sourceshelf serve`, GET only, 127.0.0.1)

- `/api/search?q=<text>&limit=<1..MAX>&fields=1&kind=own|external` returns `{"results": [...]}` with id, title, url, domain, fiche, path, page, line, snippet, year and authors. It is a richer shape than the CLI's `--json`.
- `/api/sources` returns configured sources, domain counts, `fiche_count` and `unverified_count`.
- Errors return `{"error": "internal error"}` with status 500; a foreign `Host` header gets 403.
- The server is single-threaded and reloads the search cache per request; it suits libraries up to a few thousand fiches.

## Network and safety limits

`sourceshelf add` and `sourceshelf run` accept only http and https URLs, refuse hosts that resolve to non-public addresses (also after redirects; set `KB_ALLOW_PRIVATE=1` for an intranet), and refuse responses over 50 MB. `KB_ENDPOINT` must be https (http only for localhost). docx files with a DTD or an oversized text part are refused.

## Resolving keys

`sourceshelf resolve <key>` accepts a fiche id, an entry of `e-ids`, or a `legacy-path` (also `legacy-path-extra`): an exact path, or a folder ending in `/` for every fiche below it. Use `legacy-path` to keep old references from another system working after import.

## Requirements and scale

`pdftotext` (`poppler-utils`) for PDFs; `rg` (`ripgrep`) for `--exact`; a missing tool gives a message naming the package (exit 1; during `sourceshelf add` the fiche gets `status: new` and an `error:` line); optional `faster-whisper` for audio (the `small` model must be downloaded beforehand: it loads with `local_files_only=True`). Measured on synthetic libraries of 413 / 2065 / 8260 fiches: `sourceshelf search` warm 0.3 / 1.1 / 3.9 s, BM25 cache 8 / 41 / 164 MB.
